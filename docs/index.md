# Meditated Sleeping

Calm black-screen music for deep sleep, relaxation, and focus.

This is the homepage for **Meditated Sleeping**, a personal, single-user automated tool
that creates original ambient/calm-music videos (rain, deep sleep, nature sounds,
meditation frequencies) and uploads them to the owner's own YouTube channel.

- ▶ YouTube channel: Meditated Sleeping
- 🔒 [Privacy Policy](privacy-policy)
- 💻 [Source code](https://github.com/oceanfarm1992-design/blackscreen-youtube-automation)

All music is original, created with the help of AI for a calm listening experience.
This content is for relaxation and ambience only and is not a substitute for medical
advice or treatment.
