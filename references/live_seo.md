# Live Stream SEO Pack

Copy-paste titles, descriptions, and tags for each 24/7 live stream. Set these in
**YouTube Studio → your live broadcast → Edit** when you create each stream.

Rules baked in (per channel policy): **no age-restriction words**, strong search
keywords, and a diplomatic "created with AI" note in every description.

**Tips**
- Title ≤ 100 chars. Lead with the top keyword; `24/7` + `LIVE` help live discovery.
- YouTube tags total cap ≈ 500 characters — put the strongest keywords first.
- Only the first ~3 `#hashtags` show above the title; the rest still help search.
- Use the **black `#0D0D0D` thumbnail** for all of them (channel identity).
